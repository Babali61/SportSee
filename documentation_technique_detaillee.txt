1. INTRODUCTION
--------------
Le projet SportSee est une application de suivi d'activité sportive développée avec React et D3.js. 
Cette documentation détaillée explique le développement technique de chaque composant et fonctionnalité.

  .domain(data.map((d) => d.day))
  .range([0, width])
  .padding(0.8);

const y = d3.scaleLinear()
  .domain([0, d3.max(data, d => d.value)])
  .range([height, 0]);

// Création des barres
svg.selectAll(".bar")
  .data(data)
  .enter()
  .append("rect")
  .attr("class", "bar")
  .attr("x", d => x(d.day))
  .attr("y", d => y(d.value))

  .attr("height", d => height - y(d.value));

5. OPTIMISATIONS TECHNIQUES
-------------------------
5.1 Hook useResizeObserver
- Développement :
  * Utilisation de ResizeObserver API
  * Optimisation avec requestAnimationFrame
  * Nettoyage automatique
- Code clé :
```javascript
const useResizeObserver = (ref) => {
  const [dimensions, setDimensions] = useState(null);
  
  const resizeCallback = useCallback((entries) => {
    requestAnimationFrame(() => {
      setDimensions(entries[0].contentRect);
    });
  }, []);
  
  useEffect(() => {
    const resizeObserver = new ResizeObserver(resizeCallback);
    resizeObserver.observe(ref.current);
    return () => resizeObserver.disconnect();
  }, [ref, resizeCallback]);
  
  return dimensions;
};
```
