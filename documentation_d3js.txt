DOCUMENTATION D3.JS - PROJET SPORTSEE
====================================

1. INTRODUCTION À D3.JS DANS LE PROJET
-------------------------------------
D3.js (Data-Driven Documents) est utilisé pour créer des visualisations de données interactives et dynamiques.
Dans SportSee, D3.js est utilisé pour trois types de graphiques :
- Graphique à barres (activité quotidienne)
- Graphique radar (performances)
- Jauge circulaire (score)

2. PRINCIPES DE BASE DE D3.JS
----------------------------
2.1 Sélection et Manipulation du DOM
- Utilisation de select() et selectAll()
- Chaînage de méthodes
- Manipulation des attributs avec attr()
- Ajout d'éléments avec append()

2.2 Échelles (Scales)
- scaleBand() : pour les axes catégoriels
- scaleLinear() : pour les axes numériques
- scaleOrdinal() : pour les couleurs
- Configuration des domaines et ranges

2.3 Transitions et Animations
- transition() pour les animations
- duration() pour la durée
- delay() pour les délais
- ease() pour les fonctions d'accélération

3. IMPLÉMENTATION DES GRAPHIQUES
-------------------------------
3.1 Graphique d'Activité Quotidienne
- Structure :
  * SVG conteneur
  * Axes X et Y
  * Barres de données
  * Tooltips
  * Grille de fond

- Code clé :
```javascript
// Configuration du SVG
const svg = d3.select(svgRef.current)
  .attr("width", dimensions.width)
  .attr("height", dimensions.height)
  .append("g")
  .attr("transform", `translate(0,${margin.top})`);

// Échelles
const x = d3.scaleBand()
  .domain(data.map((d) => d.day))
  .range([0, width])
  .padding(0.8);

const y = d3.scaleLinear()
  .domain([0, d3.max(data, d => d.value)])
  .range([height, 0]);

// Création des barres
svg.selectAll(".bar")
  .data(data)
  .enter()
  .append("rect")
  .attr("class", "bar")
  .attr("x", d => x(d.day))
  .attr("y", d => y(d.value))
  .attr("width", x.bandwidth())
  .attr("height", d => height - y(d.value));
```

3.2 Graphique Radar
- Structure :
  * SVG conteneur
  * Axes radiaux
  * Polygones de fond
  * Ligne de données
  * Labels

- Code clé :
```javascript
// Calcul des angles
const angleSlice = (Math.PI * 2) / data.length;

// Fonction de ligne radar
const radarLine = d3.line()
  .x((d, i) => radius * (d.value / 250) * Math.cos(angleSlice * i - Math.PI / 2))
  .y((d, i) => radius * (d.value / 250) * Math.sin(angleSlice * i - Math.PI / 2))
  .curve(d3.curveLinearClosed);

// Création des niveaux
for (let i = 0; i < levels; i++) {
  const levelData = data.map(d => ({
    value: ((i + 1) / levels) * 250,
    kind: d.kind
  }));

  svg.append('path')
    .datum(levelData)
    .attr('d', radarLine)
    .attr('fill', '#CDCDCD')
    .attr('fill-opacity', 0.1);
}
```

3.3 Graphique de Durée Moyenne des Sessions
- Structure :
  * SVG conteneur
  * Ligne de progression
  * Points de données
  * Tooltips interactifs
  * Curseur personnalisé
  * Fond dégradé

- Code clé :
```javascript
// Configuration du dégradé
const gradient = defs.append("linearGradient")
  .attr("id", "line-gradient")
  .attr("x1", "0%")
  .attr("y1", "0%")
  .attr("x2", "100%")
  .attr("y2", "0%");

gradient.append("stop")
  .attr("offset", "0%")
  .attr("stop-color", "rgba(225, 225, 225, 0.7)");
gradient.append("stop")
  .attr("offset", "100%")
  .attr("stop-color", "rgb(225, 225, 225)");

// Échelles
const xLine = d3.scaleLinear()
  .domain([0, dataWithInitials.length - 1])
  .range([0, 500]);

const y = d3.scaleLinear()
  .domain([0, d3.max(dataWithInitials, d => d.sessionLength)])
  .nice()
  .range([300, 90]);

// Fonction de ligne
const line = d3.line()
  .x((d, i) => xLine(i))
  .y(d => y(d.sessionLength))
  .curve(d3.curveCatmullRom.alpha(0.5));

// Création de la ligne
g.append("path")
  .datum(dataWithInitials)
  .attr("fill", "none")
  .attr("stroke", "url(#line-gradient)")
  .attr("stroke-width", 4)
  .attr("d", line);

// Points interactifs
g.selectAll(".dot")
  .data(dataWithInitials)
  .enter().append("circle")
  .attr("class", "dot")
  .attr("cx", (d, i) => xLine(i))
  .attr("cy", d => y(d.sessionLength))
  .attr("stroke", "url(#line-gradient)")
  .attr("r", 5)
  .attr("fill", "white");
```

- Fonctionnalités spécifiques :
  * Dégradé de couleur pour la ligne
  * Points interactifs avec tooltips
  * Curseur personnalisé au survol
  * Animation des points
  * Gestion des états de survol

- Interactivité :
  * Tooltips au survol des points
  * Curseur personnalisé qui suit les données
  * Animation des points au survol
  * Affichage de la durée en minutes

3.4 Jauge (Score)
- Structure :
  * SVG conteneur
  * Arc de fond
  * Arc de progression
  * Texte central
  * Labels

- Code clé :
```javascript
// Configuration de l'arc
const arc = d3.arc()
  .innerRadius(innerRadius)
  .outerRadius(outerRadius)
  .startAngle(startAngle)
  .endAngle(d => startAngle + (endAngle - startAngle) * d.value);

// Création de l'arc de fond
svg.append('path')
  .datum({ value: 1 })
  .attr('d', arc)
  .attr('fill', '#f8f8f8');

// Création de l'arc de progression
svg.append('path')
  .datum({ value: score / 100 })
  .attr('d', arc)
  .attr('fill', '#ff0000');
```
